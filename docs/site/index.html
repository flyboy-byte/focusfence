Focus Fence AC

A website and content blocker for Android that keeps its work on the phone, with optional accountability: one or more partners, or a group of up to six people, who are told when protection is switched off or something risky is seen.

Every layer is a separate switch. With all of them off it is only the on-device blocker.

  • Privacy: what is collected, where it goes, how long it stays
  • Limits: what it cannot do
  • Run your own accountability server

Free and open source (AGPL-3.0). The project page says which features have been tried on a real phone.

Focus Fence AC

A website and content blocker for Android that keeps its work on the phone, with optional accountability: one or more partners, or a small group of up to four phones, who are told when protection is switched off or something risky is seen.

Every layer is a separate switch. With all of them off it is only the on-device blocker.

  • Privacy: what is collected, where it goes, how long it stays
  • Limits: what it cannot do
  • Run your own accountability server

This is an unreleased work in progress. Each page says what has and has not been tested on a real phone.

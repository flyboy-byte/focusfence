Run your own server

The accountability server is optional and self-hostable. It needs HTTPS (the app only talks to https:// servers).

cd server/deploy
cp .env.example .env     # FF_PUBLIC_URL, RESEND_API_KEY, FF_MAIL_FROM, FF_DOMAIN
docker compose --profile https up -d

Full instructions, environment settings, backups and security notes are in server/README.md in the repository. The Docker Compose setup has been run end to end from source; fetching a real public certificate with Caddy has not been tested.

In the app: Partners, then Join with a code (an enrollment code from your server's admin page), or enter the address and code under Server.

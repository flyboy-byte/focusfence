Run your own server

The accountability server is optional and self-hostable. It needs HTTPS (the app only talks to https:// servers).

cd server/deploy
cp .env.example .env     # FF_PUBLIC_URL, RESEND_API_KEY, FF_MAIL_FROM, FF_DOMAIN
docker compose --profile https up -d

Full instructions, environment settings, backups and security notes are in server/README.md in the repository. The Docker Compose file and Caddy setup have not yet been run end to end; say so in any bug report.

In the app: Settings, Accountability, enter your server address (and the enrollment code if you set one).
